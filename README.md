# Smart-Farming-AI

## About the Project
Smart Farming AI is an AI/ML-based project focused on
using technology and machine learning to support
smarter farming decisions.

## Project Objectives
- Explore AI and Machine Learning applications in agriculture.
- Analyze farming-related data.
- Build practical machine learning solutions.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Structure
- dataset/ - Stores datasets.
- notebooks/ - Contains Jupyter notebooks.
- models/ - Stores trained ML models.
- images/ - Stores project images.
